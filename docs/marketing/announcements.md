## 長文(ブログ・配布先)

Asteria(アステリア)は、変換の正確さを何より優先した Windows の日本語入力です。PC の GPU で AI を動かし、直前の文まで
読んで、文脈に合う漢字を最初の候補に出します。打った文章は外へ送りません。

v5.2.0 では、普段使いで気になる点を直しました。

- アプリや入力欄を移っても、最後に自分で選んだ入力モード(日本語入力のオン・オフ、ひらがな・カタカナ)を保ちます。
- パスワード欄では AI と学習を止めます。
- AI が使えるようになるまでの時間を短くしました(10.6 → 3.9 秒)。
- NVIDIA の GPU 向けに、Space の変換を速くする追加パッケージ(任意)を用意しました(中央値 185 → 137 ミリ秒)。

今の版で、Google日本語入力 3.34.6260 と同じ PC・同じ打ち方で実際に入力して比べました。Space で出た最初の候補が正しかった
割合は、前の文で正解が決まる同音語 300 問で Asteria 91%・Google 45%、日常の短文 500 問で 95%・87% です
(短文は表記ゆれを同じとみなす。調整に使っていない問題)。
