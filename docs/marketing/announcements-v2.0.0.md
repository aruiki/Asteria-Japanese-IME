## 更新内容と確認範囲

Asteriaは、意図した言葉への変換を辞書とローカルAIで支える日本語IMEです。正式v2.0.0はMozcの辞書・文節処理・学習と、ローカルAIの候補生成・採点を組み合わせます。モデル・実行環境をMSIへ同梱し、文章は外部サーバーへ送信しません。

AIの準備中も読みの表示・編集・取消を続けられ、通常は最初の生成・採点結果が完成してから候補を表示します。保留確定後に古い未確定表示が残る原因を修正し、同じ文を意図して2回入力する動作は保持しました。

同じMSIの導入・再導入・入力・削除、候補操作8項目、EDIT/RichEditの二重入力28条件、Edgeのtextarea/contenteditableの14条件を確認しました。全アプリやGPU実機の導入TSF、低性能実機、保護欄内部、旧版更新、再起動、独立した製品完成判定の確認ではありません。MSIは未署名です。
