# v3.0.0 紹介動画の要件（2026-10-24 利用者と決定）

公式サイトと README に置く。Asteria の良さ（文脈を読む正確さ、毎日の文章の自然さ、プライベートであること）を、
誇張せず落ち着いた表現で伝える。

## 決めたこと（利用者の回答）

- 長さ: 約30秒。
- Google日本語入力との比較: グラフで見せる。「前の文で決まる同音語」と「日常の短文」の2つ。
- 音: サイト用は既存の静かな BGM と効果音（実際にキーを送った時刻の打鍵音、Space で変換した瞬間の小さな音）。README 用は音なし。
- 実際の入力の録画: Word、Chrome（公開ページの入力欄）、Asteria の設定画面。仮の画面は使わない。

## 表現の決まり

- しつこい言い回しを避ける。「完全ローカル生成」のような技術の押し付けはしない。伝えるなら「プライベート」
  「入力した文章は外へ送りません」程度にとどめる。
- 数字は条件と一緒に出す（同じ PC・同じ打ち方・調整に使っていない問題・測った版と日付）。条件のない「〇倍」などは使わない。
- Google日本語入力は名前の文字だけで示し、ロゴや画面は使わない。

## 正直さの決まり

- 映す変換はすべて本物の Asteria の入力で、ローマ字を続けて打ち Space を1回押した直後の第一候補だけを使う。
  候補を選び直した結果は映さない（2026-10 に手で選んだデモを取り下げた経緯がある）。
- 録画のたびに、打った読み・Space 後の文字・確定した文字を記録し、記録と映像が一致しない撮り直しは捨てる。
- グラフの数字は v3.0.0 の候補（最終 MSI）で測り直す。Google日本語入力は 2026-10-23 の同条件の測定（3.34.6260）を使い、
  版と日付を画面に小さく書く。
- 設定画面の数字は、この PC で実際に数えたものだけを映す（試験用の作り物の数字は使わない）。

## 構成（約30秒、1920×1080、30fps）

| 時間 | 場面 | 内容 |
| --- | --- | --- |
| 0–3秒 | 表紙 | 月のマークと「Asteria」「変換精度の高い日本語入力」 |
| 3–13秒 | Word の実録画 | 長い文をローマ字で一気に打ち、Space 1回で文全体が正しく変換される（例「昨日買った本を読んでいたら気がついたら夜中の2時になっていた」）。字幕「前後の文脈から、まとめて変換。」 |
| 13–21秒 | 比較のグラフ | 横棒2組（前の文で決まる同音語、日常の短文）。Asteria と Google日本語入力の正解率。条件を下に小さく |
| 21–25秒 | Chrome の実録画 | 公開ページの入力欄で短い文を変換。字幕「プライベートな日本語入力。入力した文章は外へ送りません。」 |
| 25–28秒 | 設定画面 | ダッシュボードの「今日の使い方」（実際の数字） |
| 28–30秒 | 終わり | 「無料・オープンソース」「Windows 10 / 11」「github.com/aruiki/Asteria-Japanese-IME」 |

## 書き出すもの

- サイト用: `asteria-v3-promo.mp4`（1920×1080、H.264、BGM あり）と、最初の場面の静止画（ポスター）。
- README 用: 音なしの短い版（Word の場面と比較のグラフ、約12秒）を GIF と MP4 で。GIF は 960 px 幅・10 MB 以下。
- BGM は YouTube オーディオライブラリの曲を利用者が選んで取得する（Pixabay は曲も効果音も Content ID 登録済みが多く、将来 YouTube に載せたときの申し立てを避けるため使わない）。曲名とライセンス（帰属表示の要否）を記録し、要れば動画の説明と README に書く。効果音（打鍵音・変換の音）は利用者の了承を得て Pixabay の効果音を使い、出典を `promo/assets/sfx-pixabay/SOURCES.tsv` に記録する（合成した予備の音も残す）。音のファイル単体はリポジトリに置かない（動画の中にだけ使う）。

## 録画のときの守ること

- 撮るのはソフトの文字を打つ部分の範囲だけ。タブ名・最近のファイル・アカウント名などが映らないよう切り取る。
- Word と Chrome は新しい空の文書・ログインの要らない公開ページで、打った文字がページ側に送られない欄を使う。
- 録画中は利用者に PC に触れないよう伝える。録画の後、利用者の学習データを録画前の状態に戻す。

## 完成の条件

- 上の決まりをすべて満たし、利用者が見て承認したもの。承認の前にサイトと README へ載せない。
