## Asteria v2.1.0

**変換精度の高い日本語IME。** 無料・オープンソース。オフラインで使えます。

### v2.0.0からの更新

- **数字の後の句読点を日本語のままにしました。** 「賛成96、反対3」「電話番号は…、最寄り駅は」の読点や、文末の「96。」が全角のカンマ・ピリオド（，．）に変わっていた問題を直しました。「1,000」「3.5」のように数字に挟まれた場合は従来どおりです。
- **「90ぱーせんと」を「90%」に変換します。** 変換用AIが読みどおりのカタカナを強く好み、「90パーセント」が先に出ていました。数字の直後で記号の候補がある場合は記号を選びます。
- **短い入力の語彙を補強しました。** 頻度と事前の規則で選んだ約11.5万語を追加し、単語・短文の変換候補を増やしました（出典と帰属は同梱のNOTICE-short-lexicon.txt）。
- **ひらがなで書くのが普通の語を、むやみに漢字にしないようにしました。** 「ちょうど良い」→「ちょうどいい」、「下さい」→「ください」、「後で」→「あとで」のように、日常の文章でよく使われる表記を選びます。根拠は公開の会話コーパスで数えた使用比率です。文脈に強い根拠があるときは漢字のままです。
- **設定画面の品質の説明から、根拠の弱い正確さの数値を外しました。** 以前の数値は製品と構成の異なる評価方法で測ったものでした。

### 精度の測り方と結果

今回から、実際のIMEと同じ処理の経路で、公開コーパスから作った4分野の評価セット（各500問、調整に未使用）を使って測っています。表記ゆれ（見たり/観たり、わかる/分かる 等）は同じとみなします。

| 分野 | v2.1.0 |
| --- | --- |
| 日常の短文・チャット | 92.0% |
| 仕事の文書・メール | 88.8% |
| 技術・専門用語 | 91.0% |
| 固有名詞・新語 | 80.2% |

目標（短文・文書95%、専門語・固有名詞90%）にはまだ届いていません。同じPC・同じ打ち方でのGoogle日本語入力（3.34.6260）との比較では、日常の短文500問で457問対434問、前の文で正解が決まる対300問で274問対133問でした。詳しくは[検証記録](https://github.com/aruiki/Asteria-Japanese-IME/blob/main/docs/verification/release-v2.1.0-20261023.md)をご覧ください。

### 既知の問題

- 文の意味で決まる同音語（例: 駐車/注射）を誤ることがあります。
- 人名・店名などの固有名詞は、ほかの分野より誤りが多くなります。

### 導入

**Assets → Asteria64.msi** を開き、案内に従ってください。導入後は **Windows + Space → Asteria日本語入力** を選択します。GPU AIはVulkan対応の専用GPU（VRAM 3 GiB以上）を使用します。v2.0.0からは上書きで更新できます。更新後はWindowsの再起動が必要になる場合があります。
