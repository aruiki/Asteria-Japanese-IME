明るい・暗いの配色で、ホーム・AI 変換・入力の補助を撮って確かめた(動きを減らす設定で撮影)。操作: 切り替え → 「保存しました」、

## 実機(この PC、手元のビルドの mozc_tool.exe --mode=config_dialog)

- WebView2 で開き、ホームに実際の数字(今日の変換回数・考える時間・正答率)と AI の状態が出る。
- UI オートメーションで「同音語のヒント」を切り替え → 窓を閉じて開き直すと変えた値のまま → 元に戻して開き直すと元の値
  (`before=On after_toggle=Off reopened=Off restored=On`)。読み上げでは「同音語のヒント」の名前と状態が取れる。
- 修正前のビルドでは、保存に失敗したことが右上の赤い表示と理由の知らせ(「設定の値が正しくありません(character_form_rules)」)
  で示され、設定は変わらなかった。
- `ASTERIA_CLASSIC_SETTINGS=1` で今までの Qt の設定画面(題名「Asteria」)が開く。
- 「キーを 1 つずつ変える」から今までのキーの割り当ての編集画面が開く(保存せずに閉じた)。
