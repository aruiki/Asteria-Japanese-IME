# v3.0.0 の検証記録（2026-10-24）

利用者の依頼（2026-10-24）「さっそくgithubに正式版として公開しましょう」による正式版 v3.0.0 の記録。要件は利用者と質問への
回答で確定した（GOAL.md「Asteria v3.0.0 正式版の要件」）。v2.0.0（3.34.6442.100）以降の累積で、v2.1.0 として準備した
精度・速度の改善（6447、`release-v2.1.0-20261023.md`）に、次を加える。

- 画面1枚・再起動なしで更新できるインストーラー（ADR0072）、完了の画面、削除の後の知らせ。
- 入力モードの整理（カード84: 英数キーで直接入力、入力モードの全アプリ共有）。
- ダッシュボードの作り直しと使い方の数字（変換回数・考える時間・正答率・予測で節約できた時間。回数と時間だけを保存）。
- 応援の通知を3日ごと（応援の後は30日後）にし、設定の「その他」で止められるようにした。
- 候補の窓: 暗い配色の主従、選んでいる行の印、Windows 11 の角の丸め。

原票はすべて `target/accuracy-guide/` の下（リポジトリの外）。検証はこの PC（Windows 11 Pro 10.0.26300、RTX 3060）で、
本物の MSI を画面つきで導入・更新・削除して行った。管理者の確認（UAC）は利用者が承認した。

## 検証の方法で分かったこと

Claude のデスクトップアプリ（パッケージアプリ）の中で動くコマンドは、AppData への書き込みがアプリ専用の場所
（`AppData\Local\Packages\Claude_…\LocalCache`）に振り向けられる。それまでの検査の「学習履歴を戻して SHA 一致」は、
この仮想化された場所で行われていた可能性がある。6453 以降は、学習フォルダの操作と local_install_check を
タスク スケジューラ経由（`v3-final-6453/outside.ps1`、利用者の画面上・パッケージの外）で動かし、実際の LocalLow で確かめた。
