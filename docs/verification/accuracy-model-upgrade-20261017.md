## 比較候補と順序

1. **Sarashina2.2-3B（基盤モデル）**。日本語の3Bモデルとして現在の1.5B採点モデルを一段上げる直接置換候補。現実装はチャット返答ではなく、文脈に続く各候補の対数尤度を採点するため、まず基盤モデルを比較する。[提供元](https://huggingface.co/sbintuitions/sarashina2.2-3b)。採用精度・速度・GGUF互換性は未確認。
2. **Qwen3.5-4B-Base**。現世代の4B言語モデル部分を使う比較候補。公式仕様ではGated DeltaNetとAttentionの混合構造であり、現在のllama.cppと複数候補の状態複製・再利用が正しく動くかを先に確認する。画像エンコーダはIME用途に使わない。[提供元](https://huggingface.co/Qwen/Qwen3.5-4B-Base)。小さなパラメータ差だけからレイテンシ・VRAMを推定しない。
3. **Qwen3-4B-Instruct-2507**。通常のAttention構造による4B比較候補。公式モデルはnon-thinkingのみ。対話指示性能と現実装の生文章採点の精度を混同せず、候補選択プロンプトに使う場合は別実験にする。[提供元](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)。

まずLLM採点だけを入れ替え、Mozc・zenz・学習済み追加生成・候補数を固定してAJIMEEの改善/改悪を比較する。各モデルの尤度尺度は異なるため、重み1.2の直接置換と、調整用データで重みを較正した結果を区別する。モデルだけ替えた一度の悪化で能力不足と断定しない。

量子化は比較条件としてQ5_K_Mを第一候補とし、取得元revision・重み・変換ツール・GGUFのSHAを保存。文脈採点を強くしても候補欠落5件は残り得るため、次段で生成モデルも検討する。まず現在の188/200、報告された「アイデア曲」の選択、処理時間・起動時間・メモリを比較する。正解集合を変更しない。

Google日本語入力との比較は実際の同製品で確認するまで未検証とする。Mozc単独結果をGoogle日本語入力の結果として扱わない。
