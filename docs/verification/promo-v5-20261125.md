利用者の依頼「紹介動画・GIF も刷新」。[要件](../marketing/promo-video-v3-requirements.md)の「正直さの決まり」に従った。

## 録画

- 道具: `eval/imebench/PromoTyping.cs`(ImeBench と同じく、この窓だけで Asteria を有効にし、ローマ字を本物のキーとして送る)。
  1 秒に約 6 回の速さで打ち、Space を 1 回押した後の第一候補をそのまま見せ、Enter で確定した。
- IME: 利用者の PC に入っている Asteria 5.4.0(3.34.6524.100)、RTX 3060。前の文なし。
- 録画は窓の範囲だけ(`ffmpeg gdigrab` の範囲指定)。窓の縁と、打っている途中に出る予測の窓が映る部分は切り落とした
  (利用者の指摘、2026-11-25「予測タブが邪魔してる」)。ほかのアプリが映った撮り直しの映像は消した。

| | 記録 |
| --- | --- |
| 打った読み(ローマ字) | `kinoukattahonwoyondeitarakigatsuitarayonakano2jininatteita` |
| 確定した文字(Space 1 回 → Enter) | 昨日買った本を読んでいたら気がついたら夜中の2時になっていた |

同じ読みで 3 回撮り、3 回とも同じ確定の文字だった。映像の最後の画面の文字と記録は一致する。

## ほかの場面

- 精度の比較: [2026-11-11 の実入力の測定](accuracy-realinput-20261111.md)の「前の文で正解が決まる同音語」(Asteria 91%、

## 作り方

```bash
python docs/marketing/make_promo_v5.py <録画.mp4> <インストーラーの画像.png> <出力フォルダー>
```

(960 px 幅、12fps、0.8 MB)、`docs/images/promo-poster.jpg`。
