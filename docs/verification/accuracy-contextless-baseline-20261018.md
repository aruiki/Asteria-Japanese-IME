## 辞書と次の実装

[上流の辞書説明](https://github.com/google/mozc/blob/master/src/data/dictionary_oss/README.txt)は、Google日本語入力で使う大規模なWeb由来語彙がOSS Mozcに含まれないと説明している。固定Mozcソース内READMEでも同じ記載を確認した。これは基礎辞書を調べる根拠になるが、本製品の個々の誤変換の原因を確定したことにはならない。

次の精度改善は前文なし・初回・即Spaceを優先する。AI準備前に返す候補の包含/順位と、準備後の選択を分けて確認し、語彙の補充だけで直るケースと軽量な順位付けが必要なケースを分離する。AI未準備を待つためにキー同期処理へ大型モデルの読み込みを足さない。今回の数字を目的に固定語句の分岐や参照表記の書換えはしない。

低メモリ修正後の前文あり4セットは、直前705の全326出力と一致した。runtime再構築で従来精度が変わっていない確認であって、新たな精度向上ではない。MSIへの反映、初回即Spaceの改善、実TSF、Google日本語入力との同条件比較、独立verifierは未完了。
