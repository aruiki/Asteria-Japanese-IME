# 75: 実変換の誤りを抽出して内部の選択を改善

利用者は外観の移行後、変換精度を改善する内部開発と、例の抽出を含む高速デバッグを依頼。

現行mainのMozc作業ツリーから変換器をビルド。通常の利用者プロファイルを使わず、AJIMEE/日常/慣用句/ニュアンス/表記の調整セットを同条件でMozcとStandard比較し、失敗例を抽出する。heldoutは調整に使用しない。

原因を候補不足/候補選択/読み検査/文節適用/待ち時間に分けて調べる。修正前後の具体例、標準品質90%以上の条件と既存正解維持、ローカルテスト・再生成パッチを確認する。評価条件・バイナリ/モデル/データSHAを記録する。CLI評価と実アプリTSF受入れを区別する。
実施: 日本語パスのAI読み込み失敗を修正。5セット386問/53ネイティブテスト/18工具テスト/3パッチ適用確認。25不一致を抽出する再利用工具を実装。精度の全問題解消は継続。原票verification/conversion-quality-debug-20261012.md。
