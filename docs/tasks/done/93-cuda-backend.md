# 93: NVIDIA の GPU で CUDA 版の計算を使う

- 仕様: なし(配布物が増えるので docs/adr/0088 で判断する)
- 前提: なし
- 規模の目安: Mozc パッチ(読み込み・GPU の選び方・呼び出しをそろえる)と追加パッケージの WiX・CI

## 目的
変換(Space)の約 170 ms の大半は、Vulkan の小さな計算を約 20 ステップ呼ぶ時間で、設定では縮まない
(docs/adr/0088 の背景)。NVIDIA の GPU では CUDA 版の計算を使い、変換を速くする。
