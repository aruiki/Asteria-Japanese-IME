# 76: AI生成候補による文末文法語の破壊を防ぐ

カード75の抽出から「電気を消してね」が、正しいMozc候補を残したままLLMの点数で「電気を消して寝」へ逆転することを確認。語尾文字列を個別に列挙せず、Mozcの品詞と内部文節の機能語を使って生成候補の文末を保持する。

Mozcの通常候補/同音語の選択は維持し、生成した候補だけを対象にする。助詞・助動詞がある文末の変更拒否と、名詞の漢字化/内容語の同音語変更を妨げないことをテストする。修正前386問の結果と問題ごとの一致を比較し、Standard AJIMEE90%以上と既存正解非減少を確認する。heldoutは採用判断に使わない。
結果: 実例0/1→1/1、調整386問は改善1/悪化0、最終300問289→289/300（悪化0）、54テスト/3パッチ適用成功。一般CIはPRで確認。
