# 97: 打ち間違いの補正を、既定では AI を使わない軽い補正にする

- 仕様: SPEC REQ-9-3(誤補正 0.3% 以下)
- 前提: v5.3.1
- 規模の目安: パッチ 600 行ほど

## 目的
利用者(2026-11-24): AI の打ち間違いの補正は変換の時間を大きく延ばすので既定でオフにし、AI ではない軽い補正を入れる。

- [x] 軽い補正(打ち間違いの起こりやすさ × Mozc の辞書と語のつながりのコスト)を既定にする
- [x] 製品と同じ経路で Space の待ちが縮み(中央値 422 → 203 ms、p95 1047 → 391 ms)、打ち間違い以外の正解数が変わらず、
  最終評価用で正しい文を変えない([記録](../../verification/light-typo-20261124.md))
