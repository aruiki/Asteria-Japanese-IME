# 88: 軽い MSI とモデルの受け取り(5.1.0)

- 仕様: docs/SPEC.md REQ-12-4 の例外(設定画面のダウンロード)を、同梱のモデルにも広げる(利用者が承認、2026-11-03)
- 前提: カード 87(v5.0.0、追加の AI のダウンロード)

## 目的
更新のたびに約 1.55 GiB の MSI を GitHub から受け取らせない。利用者の指摘(2026-11-03)「GitHub の遅い回線を毎回
使わせるより、モデルだけ持ってきた方がよい」。

## 要件(案。作る前に利用者と確かめる)
- MSI はプログラムだけ(数十 MB)。モデル(genmai・zenz-small・TinySwallow・追加の生成器)は Hugging Face から、版と
  SHA-256 を固定して受け取る(5.0.0 の `kotori_model_download` と表を使う)。
- 同じ中身のモデルが入っていれば受け取り直さない(更新でモデルを残す)。
- 受け取りが終わるまでは AI なしの変換(Mozc と同じ)で使える。進み具合を見せる。
- オフライン用の「全部入り」MSI も同じリリースに置く。
- 変換サーバーは通信しない。
