# 93: NVIDIA の GPU で CUDA 版の計算を使えるか測り、採否を決める

- 仕様: なし(配布物が増えるので docs/adr/0088 で判断する)
- 前提: なし
- 規模の目安: 測定だけなら差分なし。採用なら Mozc パッチ(読み込み・GPU の選び方)と追加パッケージの WiX

## 目的
変換(Space)の約 170 ms の大半は、Vulkan の小さな計算を約 20 ステップ呼ぶ時間で、設定では縮まない
(docs/adr/0088 の背景)。CUDA 版で変換がどれだけ速くなるかを測り、採るかどうかをメンテナが決められるようにする。

## 手順
1. docs/adr/0088 の「判断の前に測ること」1〜5 を、公式の b11259 の CUDA 版(12.4 と 13.4)で測る。
2. 結果を docs/verification にまとめ、ADR の状態(採用 / 不採用)を更新する。
3. 採用なら、追加パッケージ・読み込み・GPU の選び方・設定を別の PR で実装する。

## 完了条件
- [ ] 速さ・精度・GPU のメモリ・起動・戻りの数値が verification にある
- [ ] メンテナが ADR 0088 の「決めてほしいこと」に答え、ADR の状態が更新されている
