# 92: 誤変換の報告(直近の変換を残す)

- 仕様: SPEC 14.1(回帰ゴールデン)、ADR0087
- 前提: 91(回帰ゴールデン)
- 規模の目安: 保存クラス・設定項目・設定画面・テスト

## 目的
実際に使っていて見つけた誤変換を、あとから読み・前の文・候補つきで取り出せるようにする。
外へは送らず、利用者が書き出したファイルだけを評価セットへ足す。

## 手順
1. `session/kotori_recent_conversions`(20 件、base64 のタブ区切り、原子的に保存)。
2. `session/session.cc` の確定時に、設定がオンのときだけ記録(パスワード欄・シークレットは除く)。
3. `protocol/config.proto` に `kotori_recent_conversions`(既定オフ)。
4. 設定画面の「プライバシー → 誤変換の報告」に、スイッチ・直近 5 件・書き出し・消去。
5. テスト: 保存クラス、ブリッジ、設定の往復、実機のセッション経路。

## 完了条件
- [x] 単体テスト(保存クラス・ブリッジ)が通る(保存 6 件、ブリッジ)
- [x] 実機のセッション経路で、オンなら記録され、オフなら記録されない
- [x] 設定画面で確認・書き出し・消去ができる(プレビューで表示、ブリッジのテストで書き出し・消去)
- [x] パスワード欄とシークレットモードで記録されない(検査用コマンドで確認)
- [ ] 導入済み TSF の実入力と保存ダイアログ(CI の MSI で確認)
