## 目的
リンクを開いたら永久停止、「いいえ」や閉じる操作は7日後に再表示する。
入力内容を取得せず、入力処理から独立して表示する。

## 実装
専用mozc_toolモード、プロファイル内support-reminder.ini、独立した定期起動。
表示前に7日後を保存し、強制終了・再起動でも短期間に再表示しない。
Windowsの操作が15秒以上止まり、通常デスクトップにいる時に前面を奪わず表示する。
ブラウザーの起動失敗は永久停止にしない。更新時も同じプロファイルの状態を使う。

## テスト
新規プロファイル、7日境界、保存の継続・時計の巻戻り、固定URLと永久停止、ブラウザー失敗、いいえ、閉じると非アクティブ表示、保存失敗の7テスト。
CIで実MSIの導入・日本語入力・削除と関連テストを確認する。
