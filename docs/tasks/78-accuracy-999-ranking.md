# 78: 99.9%を目標に、辞書候補の採点取りこぼしを修正する

- 仕様: REQ-6-2, REQ-9-2, REQ-14-2
- 前提: v1.1.3公開と公開後再取得検証の成功（2026-10-12に完了）
- 利用者指示: リリース後は変換精度99.9%を目指して開発を進める

## 目的と判定

先頭の変換結果の精度を改善する。現在のStandard AJIMEE183/200=91.5%、独立heldout289/300=96.3%を出発点にし、実例の誤変換を再現して減らす。99.9%は未達成の目標であり、意味未判定の大量ケースを正解として数えない。200問では99.9%を分解できず、独立評価の規模と範囲も今後広げる。

## 読むもの

ADR0016の採点配分、lm_rewriter.cc/h、カード77の再現原票、docs/LARGE_INPUT_CAMPAIGN.md。

## 最初の実験

「おふろわいたよ」は正解候補「お風呂沸いたよ」が存在し、LLMは正解を高く採点するが、zenzとLLMの現在配分（1:0.7）で逆転する。「ありがとうごさいます」も自然な補正候補が存在するが採用閾値に届かない。
現行0.7と1.0などの配分を同じモデル/データ/プロファイル条件で調整セットへ通し、改善/悪化を問題ごとに比較する。性能向上とは主張しない。heldoutを配分の選択に使わない。採用判断後の最終報告だけに使用する。
