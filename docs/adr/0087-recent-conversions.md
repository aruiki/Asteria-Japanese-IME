# 0087: 誤変換の報告用に直近の変換を残す

- 日付: 2026-11-05
- 状態: 採用
- 関連: カード 92、SPEC 14.1(回帰ゴールデン)、docs/verification/regression-golden-20261105.md

## 背景
実際に使っていると誤変換に気づいても、そのときの読み・前の文・候補が残らないため、評価セットへ
1 問ずつ足す作業ができない。Google 日本語入力のような利用者全体の統計は、この製品の
「外へ送らない」約束と両立しない。ローカルで完結する記録の入口が必要。

## 決定
- 設定「誤変換の報告」(`kotori_recent_conversions`、既定オフ)をオンにしたときだけ、変換の確定時に
  直近 20 件をこの PC に残す。
- 残すのは、時刻・1 番目の候補のまま確定したか・読み・確定した語・直前の文(末尾 96 文字)・
  文節ごとの候補(全体で 40 件)。保存するのは利用者のプロファイルの
  `asteria_recent_conversions.txt` だけで、外へは送らない。
- 設定画面の「プライバシー → 誤変換の報告」から、内容の確認・書き出し(利用者が選んだ場所)・消去ができる。
- 記録しない場合: 設定がオフ、シークレットモード、パスワード欄(既存の `KotoriCountsUsage` と同じ条件)。
- 保存の形は 1 行 1 件のタブ区切りで、文字は base64。タブや改行を含む文でも壊れない。
- 回帰ゴールデン(`eval/sets/asteria-regression-golden.json`)へは、書き出した内容から
  `mozc/tools/regression_add.py` で 1 問ずつ足す。

## 理由
- 自動送信をしないという約束を守ったまま、誤変換をデータへ変える最短の経路になる。
- 既定オフなので、これまで「入力した文章や読みは保存しない」としてきた使い方の統計
  (`asteria_usage.txt`)の意味を変えない。
- 直近 20 件に限るので、ディスクとプライバシーの露出を小さくできる。

## 影響
- オンにすると、確定した文章の一部がこの PC に残る。設定画面と README に明記する。
- 変換の確定時に小さなファイル(最大 20 件)を書き換える。キー入力の経路には入れない。
- 設定をオフに戻しても、すでに書いたファイルは残る。消すのは設定画面の「消す」から行う。
