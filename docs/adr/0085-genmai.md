# 0085. 変換の中心の zenz を genmai-310M にする

- 状態: 採用
- 日付: 2026-11-03
- 関係: docs/adr/0015(zenz と小さい LLM)、0031(Unreal の追加生成)、0074・0076(打ち間違いの補正)

## 背景

同梱のモデル(zenz-v2.5-small・medium、TinySwallow-1.5B)では、品質の段階や重みをどう変えても精度が動かなくなった
(High は開発用 1332 問で Standard と同じ、Unreal はかえって下がる)。利用者は「大きいモデルがどれだけ成果を出せて
軽量に使えるか」を重視し、候補のダウンロードを許可した(2026-11-03)。

候補を調べた。

| 候補 | 大きさ | 公表値(AJIMEE-Bench) | ライセンス |
| --- | --- | --- | --- |
| zenz-v3.2-small | 95M | 85.5〜86.0% | Apache-2.0 |
| genmai-310M(subdiox) | 310M(zenz-v2.5-medium を変換用に追加学習) | 95.0% | CC BY-SA 4.0 |

zenz-v3.2-small の GGUF は Asteria の llama.cpp で読めなかった(AI が error)。genmai は GGUF がないので、zenz と
同じ手順で変換した(`training/genmai/`、llama.cpp は third_party のコミット固定)。

## 決めたこと

1. **変換の中心の zenz(生成と採点)を genmai-310M にする**(Standard・High・Unreal、GPU のない PC)。
   Eco(docs/adr/0086)は zenz-v2.5-small。zenz-v2.5-medium は同梱をやめる(genmai と同じ大きさで差し替え。MSI は
   ほぼ同じ)。
2. **genmai の入力の形**: 左文脈を読みの前に置き、先頭に `<s>` を置く(zenzlc: `<s> U+EE02 左文脈 U+EE00 読み
   U+EE01`)。ファイル名が genmai・zenz-v3 のモデルで自動で切り替える(`ZenzScorer::Open`)。`<s>` なしでは打ち間違いが
   14/40 に下がった。
3. **打ち間違いの補正は zenz-v2.5-small で判定する**。補正の関所と事後確率の境目は small の点に合わせて決めてある。
   genmai の点のまま補正を探すと、補正が試されにくくなる(打ち間違い 24 → 14)。ただし、まず genmai の点で自然な
   文か見て、自然なら補正を試さない(small で採点し直すと点が低めに出て、自然な文でも補正の探索が走り、重い文の
   Space の待ちが延びた)。
4. 精度の判定(調整に使わないセット)は報告にだけ使った。

## 結果(RTX 3060、`session_eval.py --context`)

| セット | zenz-v2.5-small(前の Standard) | genmai |
| --- | ---: | ---: |
| 普段使いの判定用(120) | 116 | **118** |
| 文脈の選択の判定用(297) | 214 | **225** |
| 文章の判定用(233) | 194 | 193 |
| 文脈の選択の開発用(297) | 221 | **235** |
| 文章の開発用(232) | 199 | 201 |
| 人名(40)・日常(81) | 39・79 | 40・78 |
| 短文(120)・同音語(40)・表記(60) | 同じ | 同じ |
| 打ち間違い(40、手を止めてすぐ Space) | 24 | 20 |
| 打ち間違い(40、1.5 秒待って Space) | 27 | 28 |

- GPU のない PC(CPU): zenz-v2.5-medium と genmai で正解数・速さとも同じ(短文 119/120、日常 79/81)。
- 試して採らなかったもの: genmai を候補を増やす 2 つ目のモデルにする(文脈の選択 217、下がる)、生成の本数を減らす
  (打ち間違いは戻らない)、半精度を使わない計算(zenz-v2.5-medium の崩れの仮説。改善なし)。
- 打ち間違いの補正は、手を止めてすぐ Space を押すと下がる。genmai の変換に少し時間を使うので、裏の補正の探索が
  Space に間に合わない(少し待てば Standard を上回る)。利用者の判断(2026-11-03)で、精度の向上を優先して採用した。
- 数値と原票は docs/verification/v5-models-20261103.md。
