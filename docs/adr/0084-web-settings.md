# 0084. 設定画面を HTML(WebView2)で作り直す

- 状態: 採用
- 日付: 2026-11-03
- 関係: docs/adr/0017(Fluent 風の見た目)、0028(ハイコントラスト)、0083(設定画面の作り直し)

## 背景

利用者の依頼(2026-11-03)は「設定ソフトの質を格違いに高める」。0083 で Mozc の Qt の設定画面(Qt Widgets)を
左の一覧・検索・カードの形に整えたが、利用者は「仕組みの縛り」(標準の部品の見た目、アニメーションや自由な配置の
難しさ)を外したいと選んだ。「コストは気にしない」とも言われている。

選んだ方法は 3 つを比べた。

| 方法 | 見た目の自由さ | 手間・危うさ |
| --- | --- | --- |
| 今の Qt Widgets を描き方から作り込む | 中(Web ほど自由でない) | 小 |
| **HTML を WebView2 で出す** | **大**(アニメーション・暗い配色・拡大に強い) | 中(新しい受け渡し。WebView2 のない PC) |
| Qt Quick(QML)を足す | 大 | 大(Mozc の Qt は qtbase だけ。部品集のビルドから変え、MSI が数十 MB 増える) |

## 決めたこと

1. **設定画面を HTML・CSS・JS で作り、Edge の表示部品(WebView2)で開く。** 画面のファイルは mozc_tool に Qt の
   リソースとして埋め込み、`https://settings.asteria.invalid/` という名前でこの窓の中だけに出す
   (`WebResourceRequested` で埋め込んだファイルを返す)。インストーラーにファイルを足さない。
2. **ネットワークに出ない・ほかの所へ移らない。** 埋め込んだ拡張子(html・css・js・svg)だけを返し、
   Content-Security-Policy で外への接続・インラインのスクリプトを止める。設定画面の外への移動と新しい窓は取り消す。
   開発者ツール・右クリックのメニュー・ブラウザーのショートカット(F5・Ctrl+P など)・自動入力は切る
   (`ASTERIA_SETTINGS_DEVTOOLS` を付けたときだけ開発者ツールを使える)。応援のページだけは、決まった URL を
   既定のブラウザーで開く。
3. **設定の読み書きは今までと同じ仕組み(変換サーバーへの GetConfig・SetConfig)。** 画面と mozc_tool の間は
   JSON のメッセージ(`KotoriSettingsBridge`)。画面が読み書きできる項目は表(`kFields`)に載せたものだけで、
   型と範囲を確かめ、1 つでも合わなければ何も書かない。キーの割り当て・ローマ字の表のような大きな値は画面に渡さず、
   保存のたびに書き戻す。診断情報の保存は、画面から文を受け取らず、mozc_tool で作り直す。
4. **変えたらすぐ保存する**(Windows 11 の設定アプリと同じ)。「保存しました」を右上に出し、失敗したら理由と
   「もう一度」を出す。新しく開いたアプリから効く項目・再起動が要る項目は、保存のときに知らせる。
5. **WebView2 の実行環境がない PC、作れなかったとき、`ASTERIA_CLASSIC_SETTINGS` を付けたときは、今までの Qt の
   設定画面を開く。** キーの割り当て・ローマ字の表の編集とユーザー辞書は、今までの Qt の画面を呼ぶ。
6. **見た目**: ブランドの濃紺と金。明るい・暗いは Windows の設定に従い(題名の帯も合わせる)、ハイコントラストでは
   Windows の配色だけを使う。動きを減らす設定(prefers-reduced-motion)ではアニメーションを止める。部品はキーボード
   だけで使え(Ctrl+F で検索、Ctrl+Tab でページ、矢印で段の選択)、読み上げ用の名前を付ける。
7. ホーム・AI の状態・使い方の数字は Qt の画面と同じ部品(`kotori_settings_data`)から作る。
8. 今までの Qt の画面(以前の設定画面・キーの割り当て・ローマ字の表・ユーザー辞書)は、同じ濃紺の Fluent の見た目
   (`gui/base/kotori_style.h`)にそろえる。ブランドの印は、アイコンと同じ細く鋭い三日月にする。

## 確かめ方

- `//gui/config_dialog:kotori_settings_bridge_test`: 読み込み・保存・載せていない項目と範囲外の値の拒否・
  途中まで書かないこと・全角半角の表・自分で変えたキーの割り当て・Windows の設定・診断情報の作り直し。
- 見本のデータでの画面(WebView2 の外では見本で動く): 明るい・暗い、各ページ、検索、切り替えと保存の表示。
- 導入した MSI で、設定画面が WebView2 で開き、変えた設定が変換サーバーに届くこと(実機)。

## 残すこと

- WebView2 の実行環境は Windows 10/11 にほぼ入っているが、入っていない PC では今までの画面になる。
- 説明の文と項目の意味は 0083 から引き継いだ。品質の説明は 2026-11-03 の測定(High は Standard と同じ、
  Unreal は打ち間違いの補正が減る)に合わせて書き直した。
