# 0063: 近い辞書候補をLLM採点から取りこぼさない

- 日付: 2026-10-12
- 状態: 採用候補、ローカル検証済み。CIと統合を残す
- 関係: ユーザーのリリース後99.9%へ向けた開発指示、カード78、ADR0016

## 問題

「配置し、それをかくさんばんにてパネル上に拡散して直接照射」の正解「拡散板」がMozc候補に存在するが、zenzの上位4件を生成候補が占め、LLM採点は-infのまま。元の辞書1位「拡散版」は採点されても、読み支持が近い「拡散板」は比較対象に入っていない。

## 判断

zenz上位と必須の辞書1位を維持し、その辞書1位からlog score差2.0以内の辞書候補を最大2件だけ追加採点する。有限値・範囲・重複を確認し、近い候補から選ぶ。LLM採点数0では追加も0、LLMなし/CPUでは経路を変更しない。生成候補の枠を削らず、追加計算を制限する。

語や文章のホワイトリストを持たない。入力補正、文末、ユーザー辞書、入力世代の既存ガードは維持する。既定LLM配分0.7と誤入力補正の閾値は変更しない。

## 試した重み変更と却下

一律1.0は調整466問で3改善/1悪化、1.2は6改善/2悪化。読み支持と文脈差を守るガード付き1.0は3改善/0悪化だったが、採用判断後の独立heldoutが289/300→288/300へ悪化。重み変更とそのガードは製品ソースから除去した。原票/実験ソースはtarget/accuracy-999に保持し、FAILをPASSへ書き換えない。独立問題の内容を見て閾値を調整しない。
