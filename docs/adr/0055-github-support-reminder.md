# 0055: 週次のGitHub応援案内

- 日付: 2026-10-11
- 状態: ユーザー指定に基づく採用

初回の案内後、リンクを開くまで週に一度お願いする。初回1週間に限る案はユーザーが変更した。
「GitHubで応援する」でブラウザーを開けたら永久停止。「いいえ」、閉じる、Escは7日延期。
スター登録自体は確認しない。「登録後」ではなく「リンクを開くと以後表示しない」と明記する。
案内は通常クライアントの初回接続から独立したツールを起動して表示。サーバーの子プロセス・UI制限は変更しない。ツール内だけで週次タイマーを管理する。Windowsで無操作15秒、通常デスクトップを確認し、フォーカスを奪わず画面端に表示。全画面アプリ中は延期する。
表示前に延期状態を保存するため、再起動・強制終了・通知未回答でも連続表示を避ける。
保存失敗なら表示を控える。自動通信・入力収集はなく、利用者が押した固定GitHubリンクだけを開く。
最新引き継ぎとADR0054のユーザー指定に従いMSI・関連テストはローカルで実行する。PRで自動開始したMozcクラウドビルドはキャンセルし、成功扱いにしない。一般CIは別に確認する。
今回専用のMozc作業場所からパッチを生成する。並行中の6335の変更は取り込まない。
READMEは変更せず、v1.1.0のユーザー作成公開本文をそのまま引き継ぎ、今回の説明を末尾に追加する。
