# 0078. 内蔵 GPU で AI を動かす(試験的、既定オフ)

- 状態: 採用(試験的)
- 日付: 2026-10-28
- 関係: docs/adr/0024(GPU のない PC の Low、内蔵 GPU を使わない理由)、0035

## 背景

利用者(2026-10-28): 「内蔵 GPU への対応も同時に進めて」。0024 では、内蔵 GPU に 1.1 GB の LLM を載せて細かく
何度も呼ぶと大幅に遅く、ノート PC で固まったため、内蔵 GPU は使わず CPU の Low にした。

## 決めたこと

- 設定 `kotori_use_integrated_gpu`(既定 false)。設定画面に「内蔵 GPU で AI を動かす(試験的)」。
- 専用 GPU(VRAM 3 GiB 以上)があるときは何も変えない。専用 GPU がなく設定がオンなら、共有メモリ 2 GiB 以上の
  内蔵 GPU(`GGML_BACKEND_DEVICE_TYPE_IGPU`)を選ぶ(`LlamaGpuDevice`)。
- 内蔵 GPU では計算(zenz)だけを GPU に載せ、品質・LLM・時間の上限・長い読みの扱いは GPU のない PC と同じ
  (Low、LLM なし、0.6 秒で打ち切り)にする(`LmRewriter::HasGpu` は専用 GPU だけを真にする)。0024 で固まった
  原因(LLM と上限なしの待ち)は入れない。
- 選んだ機器は変えない(モデルは読み込んだ機器に載る)。設定の変更は PC の再起動で反映する。

## 確かめること・未検証

- この開発 PC(Ryzen 7 5700X + RTX 3060)には内蔵 GPU がなく、CI の Windows にも GPU がない。内蔵 GPU の実機での
  速さ・安定は**未検証**。そのため既定はオフにし、「試験的」と表示する。
- 専用 GPU のある PC と、設定オフの PC で挙動が変わらないこと(GPU の選び方の単体試験と、既存の評価)。
