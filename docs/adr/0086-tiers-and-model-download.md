# 0086. 段階を作り直し、追加の AI を設定画面からダウンロードする

- 状態: 採用
- 日付: 2026-11-03
- 関係: docs/adr/0018(品質の段階)、0024(GPU のない PC)、0084(HTML の設定画面)、0085(genmai)、
  docs/SPEC.md(実行時の通信)

## 背景

品質の 4 段階(Low・Standard・High・Unreal)は、中身がほとんど同じだった(High は Standard と同じ結果、Unreal は
かえって下がる)。利用者は「段階ごとに中身がはっきり違うべき」と考え、要件を次のように決めた(2026-11-03)。

- Standard は今の最善。軽い段階は用途が違うので、英語の名前の別のモード(**Eco**)にする。
- High は GPU のメモリ約 4 GB、Unreal は約 8 GB の「レベルの違うモデル」。Standard より明らかに良くなければ出さない。
- 大きいモデルは MSI に同梱できない(GitHub の 1 ファイル 2 GiB、MSI の上限 1.8 GiB)。**設定画面からダウンロード
  できるようにする**(仕様の「実行時にネットワークへ出ない」を変える。メンテナである利用者が承認)。
- 取得先は Hugging Face。公式の GGUF があればそれを、なければ利用者のアカウント(aruiki)に置いたものを使う。

## 決めたこと

1. **段階**(設定の値は今までと同じ列挙。Low の値を Eco として使う)。
   - **Eco**: zenz-v2.5-small だけ。LLM を使わず、前に読んだ LLM も GPU から下ろす。ノート PC の電池やゲーム中のため。
   - **Standard**: genmai と TinySwallow-1.5B(同梱。docs/adr/0085)。
   - **High・Unreal**: Standard の中身で、採点の LLM を追加の AI に替える(採点する候補は 8 件以上)。追加の AI が
     入っていなければ選べない。GPU のメモリが足りない PC では受け取れない。
   - GPU のない PC は、設定に関係なく genmai を CPU で動かし、LLM を使わない(今までの Low と同じ働き)。
2. **追加の AI の表**(`rewriter/kotori_model_catalog`)に、取得先(版を固定した https の URL)・大きさ・SHA-256・
   要る GPU のメモリ・ライセンスを書く。変換サーバーは、表と大きさが同じファイルだけを使う。
3. **ダウンロード**(`gui/config_dialog/kotori_model_download`、WinHTTP)。
   - 利用者がボタンを押し、確認の窓で大きさ・取得先・ライセンスを見てから始める。自動では取りに行かない。
   - 置き場はユーザーのプロファイルの `models`(インストール先は書けない)。途中まで受け取ったもの(.part)からは
     続きを受け取る。受け取り終えたら大きさと SHA-256 を確かめ、一致したときだけ使える名前にする。
   - 送るのは HTTP の GET だけ。打った文字・覚えた言葉・使い方の情報は送らない。
   - 消すボタンで消せる。消したモデルの段階を選んでいたら Standard に戻す。
4. Eco・Standard は今までどおり MSI に同梱し、ネットワークなしで動く。

## 改訂(2026-11-04、カード 90)

High・Unreal の追加の AI は、採点の LLM を **替える** のではなく **判定役** にする。Standard の採点(genmai と
TinySwallow)はそのまま使い、1 番目との点差が小さい上位の候補(既定: 点差 3 以内の 4 件)だけを大きな LLM で採点し直す。
採点役を丸ごと替えると、試したどの大きな LLM も Standard を下回り、文脈の選択の外れの 7 割は「候補にあるのに僅差で負けた」
ものだったため。会話向けの調整をした LLM(Qwen3)と 3B の素の LLM は判定役でも Standard を上回らなかった。日本語で
追加学習した素の Llama-3.1-Swallow-8B-v0.5 を、意味の選び分け(漢字の語の入れ替え)だけの判定役にすると、下がるセットなしで
判定用の文脈の選択 225 → 228/297 になったので、**Unreal** に載せた(GPU のメモリ 8 GB)。同じモデルの Q3_K_M も
225 → 229/297 で下がるセットがなく、**High** に載せた(GPU のメモリ 6 GB)
(docs/verification/v501-consistency-20261104.md)。

## 残すこと

- アンインストールしても、ユーザーのプロファイルの `models` は残る(利用者ごとのフォルダのため)。設定画面の「削除」で消す。
- 追加の AI の採否と数値は docs/verification/v5-models-20261103.md。
