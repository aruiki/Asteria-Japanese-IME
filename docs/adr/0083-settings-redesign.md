# 0083. 設定画面の作り直し

- 状態: 採用
- 日付: 2026-11-03
- 関係: docs/adr/0017(Fluent 風の見た目)、0022(AI 変換タブ)、0081(入力中の窓)

## 背景

利用者(2026-11-03): 「設定ソフトの質をもっと格違いに高めてください」。

作り直す前の設定画面を全部のタブで見た。

- 見た目がそろっていない。ダッシュボードと AI 変換のタブだけがカードの見た目で、ほかは Mozc の古い見た目(見出しの線と
  行)のまま。余白が大きく空いている。
- 言葉がわかりにくい(「候補選択ショートカット 1 -- 9」「テンキーからの入力」「「もしかして」変換」、全角・半角の表の
  「変換前文字列・変換中文字列・学習」)。ほとんどの項目に説明がない。
- 誤解を招く項目がある。「プライバシー」に「使用統計情報と障害レポート / 設定変更…(管理者の盾)」があるが、Asteria は
  何も外に送らない。
- 8 つのタブが横に並び、設定を探す手段がない。

## 決めたこと

1. **Windows 11 の設定アプリのように、左に検索欄とページの一覧、右にページを置く**(タブの見出しは隠す)。
   ページ名は ホーム・AI 変換・入力・変換と辞書・入力の補助・予測・プライバシー・その他。各ページの上に大きな見出し。
2. **設定の検索**: 見出し・項目・ボタン・説明の文字から探し、合うページだけを一覧に残し、合う項目に色を付ける
   (Ctrl+F で検索欄へ)。見つからなければ「見つかりませんでした」。
3. **キーボードだけで使える**: Ctrl+Tab・Ctrl+Shift+Tab で次・前のページ(タブを隠しても今までどおり)。
4. **全部のページをカードの見た目にそろえる**(Mozc の見出しの線を外し、まとまりを白いカードにする)。
5. **言葉を全部わかりやすくし、項目にひとこと説明を付ける**。特別な変換には例を付ける(日付と時刻: きょう → 今日の日付、
   計算: 1+2= → 3 など)。全角・半角の表は「文字・打っている間・変換した後」「前回と同じ」。
6. **製品に合わない項目を外す**: 「使用統計情報と障害レポート」を出さず、「外に送る情報」のカードに、入力した文字・
   覚えた言葉・使い方の情報を外に送らず、AI も PC の中だけで動くことを書く。
7. 「予測」のページは 0081 の要件に合わせる(予測の元・予測の候補数・予測を出し始める文字数。リアルタイム変換の項目は出さない)。

翻訳の .qm は作り直さず(パッチの道具がバイナリとして扱わないため)、文言はコードで設定する(日本語だけの製品)。

## 確かめ方

`mozc/tools/capture_window.py`(第 6 引数で検索欄に文字を打った画面も撮る)で全ページと検索の画面を撮り、崩れていないこと
を確かめる。
