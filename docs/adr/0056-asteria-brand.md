# 0056: Asteriaへの改名と「月の余白」の採用

- 日付: 2026-10-11
- 状態: ユーザーがAsteria — アステリアを選択し、開発への反映を指示

## 決定

表示ブランド名をAsteria、読みをアステリアとする。綴りはAstreriaではない。
日本神に由来するという説明は採用しない。ブランドの軸は自然に使える日本語入力。
10案の比較後、ユーザーが05「月の余白」を選択。濃紺の紙に生成りの筆の月、墨のかすれ、明朝の見出し、広い余白で統一する。製品アイコンは文字なし、READMEは横長の画像へ展開。図版のデータと文字はコードから正確に描画し、測定値・軸・条件は生成AIで改変しない。
設定・辞書ツールのアイコンを変える必要はないというユーザーの訂正を優先し、従来のアイコンを保持する。
READMEの構成・ダウンロード導線・測定値・測定時点を保持し、ユーザーの追加依頼に従って文章と図版の質感を揃える。断定や最上級を控え、利用場面と実際の動作を説明する。
旧版の実際のWindows表示と履歴のベンチマークはKotori表記を残す。

## 互換性

内部の製品名Kotori、保存先、インストール先、レジストリ、CLSID、プロファイルGUID、MSI UpgradeCode、環境変数と辞書ファイル名を維持する。
表示名を内部製品名から分離し、Windows登録には表示名Asteriaを使う。
バージョンのBUILDは6337に増やす。新しい配布版の公開と実機アップグレードは別の受入れとし、今回のビルドだけでは完了と扱わない。

## インストーラー

進行表示の内部プレースホルダーと長いファイル情報を表示せず、処理段階を短い日本語で示す。
WixUI_Minimalの進行バーは維持し、MSI ActionTextへ独自の短文を定義する。
標準UIのActionText/Template仕様は https://docs.firegiant.com/wix/schema/wxs/progresstext/ を参照。
