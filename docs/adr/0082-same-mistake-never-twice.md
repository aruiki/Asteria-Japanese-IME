# 0082. 同じ間違いを二度しない・英字は半角から

- 状態: 採用
- 日付: 2026-11-03
- 関係: docs/adr/0075(文脈つきの学習)、0081(入力中の窓)

## 背景

利用者と決めた目標(2026-11-03): 「完全に使用感が自然なソフトで、精度は普段使いで 100%」。読みだけでは決まらない語
(記者/汽車/貴社)や初めて見る語があるので文字どおりの 100% はできないが、次を測れる目標にした。

- 調整に使っていない普段使いの文で 99% 以上(今は約 97%)
- **同じ間違いを二度しない: 100%**(一度選び直した文は、次から必ずその文になる)
- 打ち間違いの補正を伸ばす、改悪ゼロ

### 測ったこと

同音語の調整用セット(`asteria-choice-dev`)で AI が取り違えた 22 文について、利用者と同じ操作(取り違えた文節へ移って
↓で選び直して確定)をしてから、同じ文をもう一度変換した(`mozc/tools/make_same_mistake_set.py` で場面を作り、
`mozc/tools/learning_flow.py` で確かめる)。

- 直す前は **13/22**。選び直しは確かに確定しているのに、同じ文で同じ間違いが戻った。原因は 3 つ。
  1. 文脈つきの学習は「AI の強い確信を古い選択で覆さない」ため、点の差が `context_margin_`(8)を超えると使わない。
  2. 手がかりの語がない短い文(「ちょっと高音なんですよ。」)は、別の文脈に引きずられないよう覚えない。
  3. 利用者が文節を切り直して確定すると、次の変換では Mozc が区切りを覚えていて文全体の候補がなく、AI を通らない
     (Mozc の学習で一部だけ直る: 登場で良かった)。
  さらに、確定のときに書き方の設定で「!」が「！」になる違いを選び直しとして覚え、AI の文と合わなくなっていた。

## 決めたこと

1. **同じ文(打った読み全体と前の文が同じ)で利用者が確定した文を、文節の区切りごと覚える。** 同じ文をもう一度変換
   したら、AI を通さずにその文を出す(`ContextHistory::LearnSentence` / `ExactSentence`、`LmRewriter` の
   `CheckResizeSegmentsRequest` の最初で判定し、AI の結果と同じく覚えておいた結果として当てはめる)。
   - 文を探す鍵は、読みと前の文のハッシュ(`ExactCue`)。文はこの PC の学習の記録(`asteria_context.tsv`)にだけ置き、
     「学習履歴のクリア」で消える。変換の取り消し(Revert)で 1 回分を取り消す。
   - 覚えないもの: 保護された欄・シークレットモード・学習を止めている設定(今までどおり)、全角・半角だけの違い、
     ひらがなのまま確定した文節がある文(F6 などで読みのまま確定したとき。覚えると次から同じ文がひらがなになる)。
   - 前の文が違えば別の文として扱う(別の文脈には広げない。語の学習は今までどおり手がかりの語で広げる)。
2. **全角・半角だけの違いは、語の学習でも覚えない。**
3. **英字は、まだ選んでいなければ半角で出す**(生成ＡＩ → 生成AI、Ｐｙｔｈｏｎ環境 → Python環境)。数字・記号は今までどおり
   全角(利用者が「９０％」を正しいと確認している)。一度選んだ書き方は覚えて次から使う(LAST_FORM のまま)。英字と
   カタカナが混ざって書き方がそろわない語は、そのまま出す(半角カナにしない)。
   `CharacterFormManagerImpl::GetCharacterFormFromStorage` の既定値だけを変えた。

4. **打ち間違いの見積もりに、濁点・半濁点の付け忘れ・付けすぎ(ごさいます → ございます)を足す**。書き分けの迷い(ず/づ)と
   同じ率(0.5%、仮定)と見る(`KanaSlipLogRatio`)。
   - 試して採らなかったもの: 補正を試すかどうかの閾値(`typo_gate_` -1.8 → -1.5)は、打ち間違い +2 問に対して正しく打った文の
     Space の待ちの p95 が延びた(日常 3 → 37 ms、同音語の調整用 65 → 122 ms)。直す判定の閾値(`typo_posterior_` 2/3 → 0.4)は
     正しい入力を直す問が 1 つ出た。長音の「う」の抜けを思い違いに足して閾値を通す案は、おはよございます が直らず、待ちも延びた。

## 結果

- 同じ間違いを二度しない: 13/22 → 20/22(語の学習の改善)→ **22/22**(文を覚える)。起動し直し・学習のクリアでも確かめた。
  既存の学習の場面(`asteria-learning-flow-20261027`)も 5/5(ひらがなの確定は覚えない、手がかりのない文脈に広げない)。
- 英字の半角: 普段使いの判定用(調整に使わない)115 → 116/120、人名・新語 38 → 39、短文の調整用 118 → 119。外れた問 0。
- 濁点の付け忘れ: 打ち間違い 40 問で 手を止めて 23 → 24、0.15 秒 15 → 16、すぐ 16 → 17(ありがとうごさいます)。正しく打った
  9 セット(約 1000 文)で変わった問 0、Space の待ちも同じくらい。
- 数値と原票は docs/verification/hide-suggestion-window-20261102.md。
