# 0079. 同音語のヒント(既定オフ)

- 状態: 採用
- 日付: 2026-10-28
- 関係: docs/adr/0075(文脈つきの学習と、同音の語の既定の手がかり)、0077(ライブ変換)

## 背景

利用者(2026-10-28): 「精度は頭打ち。ライブ変換のようなひねった機能を選べる汎用ソフトに」「変換の選び直しが手間」。
選び直しのとき、同じ読みの語が並ぶと、どれが目的の語かを見比べる手間がかかる。

## 決めたこと

- 設定 `kotori_homophone_hints`(既定 false)。設定画面の「AI 変換」に「同音語のヒント」。
- v3.2.0 で入れた既定の手がかり(`kotori_context_defaults.inc`、同音の語 1,088 組。語ごとに見分ける手がかりの語)を
  そのまま使う。新しいデータは足さない。
- 変換の候補に、ある語と表の相手の語が両方並ぶときだけ、その語の手がかりの語を 2 つ「靴・靴下」の形で候補の説明に
  足す(`KotoriHomophoneHintRewriter`)。候補の並びと 1 番目は変えない。入力中の予測には出さない。
- 書き換えの列の最後のほう(並べ替えの後、読み上げ用の説明の前)に置く。

## 確かめること

- `kotori_homophone_hint_rewriter_test`: オフでは何もしない、両方並ぶときだけ出す、重ねない、並びを変えない。
- オフのとき、精度・Space の待ちが変わらないこと。
