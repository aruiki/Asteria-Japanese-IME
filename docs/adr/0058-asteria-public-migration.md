# 0058: 公開リポジトリと配布導線をAsteriaへ移行

- 日付: 2026-10-12
- 状態: ユーザーの「すべて移行してください」により実施

## 決定

GitHubリポジトリを `aruiki/Asteria-Japanese-IME` に改名し、説明・Topics・23件のリリース表示名・READMEと開発/公開ツールのURLをAsteriaへ統一する。READMEとリリース本文は所有者の構成を維持し、ブランドとリンクだけを必要箇所で変更する。

最新版v1.1.2に `Asteria64.msi` と対応するsha256を追加する。既存の `Kotori64.msi` は旧latest/downloadリンクとダウンロード数を引き継ぐ互換添付として残す。両MSIの内容は同一。今後の公開workflowも両名を添付し、検証ツールは新名を優先して古い版では旧名へフォールバックする。既存添付の削除・改名・上書きは行わない。

Gitタグはバージョンとソースの識別子なのでそのまま保持し、リリース表示名にAsteriaを付ける。タグの付け直しや過去のZIP/MSIの再作成は、公開済みソースとの対応と旧リンクを損なうため採用しない。内部の保存先、環境変数、辞書名、GUID、UpgradeCodeはADR0056の互換性方針を維持する。

応援通知の固定URLと生成するライセンス表示のURLはMozc作業ツリーで更新し、8テスト後にパッチを再生成する。公開中6338のバイナリは変更しない。現在の通知は旧URLから新リポジトリへ転送され、次のビルドから正規URLを直接使う。この移行でMSIの版や既存の実機受入れ結果を更新したとは扱わない。

## 検証

移行前後のリポジトリID、Stars/Forks、全GitタグSHA、23件のリリースID/公開日/区分/参照、既存添付ID/名前/サイズ/digestを照合。既存のダウンロード数が減っていないことも確認。旧2リポジトリ名の転送と旧latest/downloadファイル名のHTTP 200を確認。検証記録は `docs/verification/asteria-public-migration-20261012.md`。
