# Asteria日本語入力 使い方と困ったとき

Asteria日本語入力(以下 Asteria)を使う人のための案内です。開発の文書は [README](../README.md) の「開発者向け」から。

- [入れる](#入れる) ・ [使う](#使う) ・ [設定](#設定) ・ [更新する](#更新する) ・ [外す](#外す)
- [データとプライバシー](#データとプライバシー) ・ [困ったとき](#困ったとき) ・ [既知の制限](#既知の制限) ・ [報告する](#報告する)

## 入れる

1. [RC4のRelease](https://github.com/aruiki/Asteria-Japanese-IME/releases/tag/v1.1.4-rc.4) から `Asteria64.msi` をダウンロードして実行します
   (管理者の確認で「はい」)。
2. 入力方式に **Asteria日本語入力** が加わります。
3. ダッシュボードと設定はデスクトップとスタートメニューの「Asteria」から開けます。

必要な環境: Windows 10 1809 以降または Windows 11(64 bit)、メモリ 8 GB 以上、ディスク 1.7 GB。
GPU AIはVulkan対応の専用GPU（VRAM 3 GiB以上）を使用します。GPUがないPCはCPU向けのLow設定で動作し、GPUのStandardと品質・速度が異なります。

RC4は未署名のリリース候補です。[導入ガイド](INSTALL.md)にSmartScreenとファイル照合の説明があります。

ダウンロードした MSI が壊れていないかは、同じリリースの `Asteria64.msi.sha256` と比べて確かめられます
(PowerShell で `Get-FileHash Asteria64.msi`)。

## 使う

操作は Mozc(Google 日本語入力)と同じです。

| したいこと | キー |
| --- | --- |
| 入力方式を切り替える | Windows + Space |
| 日本語入力のオン・オフ | 半角/全角 |
| 変換・次の候補 | Space |
| 確定 | Enter |
| 文節の区切りを伸ばす・縮める | Shift + ← / → |
| 前後の文節に移る | ← / → |
| 予測候補を選ぶ | Tab |
| 変換をやめて読みに戻す | Esc |

- AI は直前に書いた文も手がかりにして、候補を選び直します。候補は AI の結果ができてから表示します。その間も読みの入力・編集・取消は続けられます。
- 打つ手が止まると、AI が裏で変換を始めます。手を止めてから Space を押せば、ほとんど待たずに候補が出ます。打ち終わってすぐ Space を押したときは、少し待つことがあります(PC と文の長さによります)。
- AI はログイン時に読み込まれ、常に準備ができています。AI を切った場合や実行できない場合は、Mozc の変換で入力を続けられます。
- 「句読点を打ったら変換する」が有効なとき、。？！を打つとその場で変換されます。続けて Space を押すと次の候補に移るので、そのまま Enter で確定してください。
- カタカナ語の英語表記も候補から選べます。アーキテクチャ → architecture、アクセシビリティ → accessibility、レストラン → restaurant など、31,068の読み・36,402組の辞書を使います。同じ読みの別の綴りも候補に残ります。
- ユーザー辞書に登録した語は、AI が書き換えません。辞書は設定の「辞書」から開けます。
- パスワードの欄では日本語入力になりません。

## 設定

設定の「AI 変換」タブ:

| 項目 | 中身 |
| --- | --- |
| 品質 | Low / **Standard(おすすめ)** / High / Unreal。GPU のない PC はどれを選んでも CPU 向けの設定(Low)で動きます。High・Unreal は候補を多く調べますが、評価では Standard との差はわずかで、Unreal は待ちが長くなります |
| AI の状態 | 実際に動いている AI と使っている GPU。「動いています」「モデルを読み込んでいます」「動いていません(理由)」 |
| 入力中に文章の誤変換を補正する | 手が止まっている間に、日本語の AI が誤変換を直します。Space を押して待っている間は省いて、すぐに候補を出します |
| AI モデル | 使うモデルのファイル(ふつうは変えません) |

品質の選び方: Standard のままで使ってください。ゲーム中などに重いと感じたら Low にします。AI は常駐するので、GPU のメモリ(VRAM)を約 1.5 GB 使い続けます。

## 更新する

新しい版の `Asteria64.msi` を、今の版の上にそのまま入れます(v0.3.0-beta.6 以降)。設定・学習・ユーザー辞書は残ります。
入力中のアプリがあると再起動を求められることがあります。

Asteria はインターネットにつながらないので、新しい版が出ても知らせません。
[Releases](https://github.com/aruiki/Asteria-Japanese-IME/releases) を見るか、GitHub でリポジトリの「Watch」→「Custom」→「Releases」を選ぶと通知が届きます。

前の版に戻すときは、一度アンインストールしてから前の版の MSI を入れます(上書きで古い版には戻せません)。

## 外す

Windows の「設定」→「アプリ」→「インストールされているアプリ」で **Asteria日本語入力** をアンインストールします。

アンインストールしても、次のデータは残ります(入れ直したときに引き継ぐため)。すべて消すときは、アンインストールの後に
このフォルダを削除します。

```
%USERPROFILE%\AppData\LocalLow\Kotori
```

## データとプライバシー

- **Asteria はインターネットに接続しません。** 変換も AI も PC の中だけで動き、入力した文字を外に送りません。
  利用状況の送信(テレメトリ)や、自動の不具合報告もありません。
- PC に保存するもの(`%USERPROFILE%\AppData\LocalLow\Kotori`):

  | ファイル | 中身 |
  | --- | --- |
  | `config1.db` | 設定 |
  | `user_dictionary.db` | ユーザー辞書 |
  | `history.db`、`segment.db`、`boundary.db` など | 変換の学習(よく選ぶ候補、文節の区切り)。Mozc と同じ |
  | `kotori_ai_status.txt` | AI の状態(GPU の名前、使っているモデル)。設定画面の表示に使う |
  | `crash\crash-*.txt` | 異常終了したときの記録(落ちた場所だけ。メモリの中身や入力した文字は書かない)。最新 5 個 |

- AI が変換のために一時的に覚える内容は、メモリの中だけに置き、ファイルには書きません。
  シークレットモード(ブラウザのプライベートウィンドウなど)とパスワードの欄では、AI も学習も使いません。
- 学習を消すときは、設定の「辞書」タブの「学習履歴のクリア」を使います。
- ログに入力した文字・読み・候補は書きません。不具合の報告にも、入力した文の中身は要りません。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「Windows によって PC が保護されました」と出て入れられない | 「詳細情報」→「実行」。署名のない版で出ます |
| 入力方式の一覧に出ない | サインアウトしてサインインし直す。「設定」→「時刻と言語」→「言語と地域」→ 日本語の「…」→「言語のオプション」→ キーボードに Asteria日本語入力 があるか見る |
| AI が動いていない(候補に AI の選び直しが効かない) | 設定の「AI 変換」タブの「AI の状態」を見る。「動いていません」なら理由が出ます。日本語を一度入力すると表示が更新されます |
| 変換が遅い・入力が固まる | 品質を Low にする。GPU のない PC では自動で CPU 向けになります。直らなければ[報告](#報告する)してください |
| ゲーム中に GPU のメモリが足りない | 10 分入力がなければ AI を外して空けます。すぐに空けたいときは品質を Low に |
| 起動して最初の候補が出るまで時間がかかる | 通常のAI経路はモデルの準備と最初の結果を待ちます。読みの表示・編集は続けられます。設定の「AIの状態」で準備中か確認できます |
| ある アプリでだけ入力できない | アプリ名と版を書いて[報告](#報告する)してください。その間は Windows + Space でほかの IME に切り替えます |
| 元の IME(Microsoft IME など)に戻したい | Windows + Space で切り替える。Asteria を既定にしたくないときは、言語のオプションで並び順を変えるか、Asteria を削除する |

## 既知の制限

- **モデルの準備中や長い読みの推論中は**、候補が表示されるまで時間がかかることがあります。通常の準備待ちでは未評価のMozc候補を先に出しません。実際の処理期限切れやAIの故障時には、入力継続のためMozcへ戻る場合があります。
- 内蔵 GPU(CPU に付いている GPU)は AI に使いません。反応が遅く、入力が止まるためです。
- 64 bit の Windows(x64)だけに対応しています。ARM 版の Windows には対応していません。
- 打ち間違いの補正(「ありがとうごさいます」→「ありがとうございます」)は、GPU があり品質が Standard 以上のときだけ、
  1 か所の打ち間違いに効きます。

## 報告する

[Issues](https://github.com/aruiki/Asteria-Japanese-IME/issues/new/choose) から、種類(不具合・誤変換・要望)を選んで書いてください。

- 不具合の報告には、**診断情報**を添付してください。設定の「AI 変換」タブの「診断情報を書き出す...」で、版・Windows・GPU・
  設定・AI の状態・異常終了の記録を 1 つのテキストにして保存できます(入力した文字は含みません。中身は保存の前に画面で見られます)。
- 診断情報を出せないときは、Asteria の版(入れた MSI のリリース名。「設定」→「アプリ」に出る版でもかまいません)、Windows の版、GPU、品質、起きたアプリと手順を書いてください。
- **入力した文の中身は、誤変換の報告で必要な読みと結果だけにしてください。** パスワードや個人の情報を貼らないでください。
- セキュリティの問題(脆弱性)は Issue に書かず、[SECURITY.md](../SECURITY.md) の方法で知らせてください。
