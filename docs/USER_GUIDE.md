# Asteria 日本語入力 使い方ガイド

純 Rust 製ネイティブ変換エンジン × ローカル GPU AI で動作する Asteria 日本語入力のユーザーガイドです。導入手順や SmartScreen については [導入ガイド](INSTALL.md) をご覧ください。

- [入れる](#入れる) · [基本操作](#基本操作) · [設定](#設定) · [更新と削除](#更新と削除) · [データとプライバシー](#データとプライバシー) · [困ったとき](#困ったとき)

## 入れる

1. [最新リリース](https://github.com/aruiki/Asteria-Japanese-IME/releases/latest) から **`Asteria-Setup.exe`** をダウンロードして実行します（管理者の確認で「はい」）。
2. NVIDIA GPU が搭載されている環境では CUDA アドオンも自動で組み込まれます。
3. **Windows + Space** で「**Asteria 日本語入力**」を選びます。設定アプリはスタートメニューやデスクトップの「Asteria」から開けます。

## 基本操作

| したいこと | キー |
| :--- | :--- |
| 入力方式の切り替え | Windows + Space |
| 日本語入力のオン / オフ | 半角/全角 |
| 変換・次の候補 | Space |
| 確定 | Enter |
| 文節区切りの調整 | Shift + ← / → |
| 文節間の移動 | ← / → |
| AI の文の続き予測を選ぶ | Tab |
| 変換をやめて読みへ戻す | Esc |

- **入力中は勝手に文字が変わりません**: 変換が走るのは Space を押したときだけです（設定で「ライブ変換」をオンにすることもできます）。
- **文脈と読みの完全整合**: 直前までの確定文脈を参照して最適な同音異義語を選び、読み整合検証（`MatchesReading` + 連濁補完）によって不自然な読み崩れを除外します。
- **カタカナ英語辞典**: `アーキテクチャ → architecture` 等 31,000 語以上の英語表記をそのまま候補から選べます。
- **パスワード欄保護**: パスワード入力欄では自動的に直接入力となり、学習や予測は一切行いません。

## 設定

設定アプリ (`asteria-config.exe`) は WebView2 ベースの UI で、変更内容は即座に保存されます。

- **AI 変換品質**:
  - **Eco**: 省電力・低 VRAM（バッテリー駆動時やゲーム中向け）
  - **Standard（既定）**: `Genmai-310M` + `TinySwallow-1.5B` の 2 段階構成で最高精度・低遅延を両立
  - **High / Unreal**: 追加モデル取得でさらなる大型モデルを利用可能（設定から取得したモデルファイルのみ受信し、入力データは一切送信しません）
- **AI 状態表示**: 使用中のバックエンド（CUDA / Vulkan / CPU）とロード状況を確認できます。
- **ユーザー辞書・学習**: 「辞書」タブで単語登録・学習履歴のクリアを行えます。ユーザー辞書に登録した語は AI によって勝手に書き換えられません。

## 更新と削除

- **更新**: 新しい `Asteria-Setup.exe` をそのまま実行します。版付き TSF DLL 機構により、開いているアプリを終了したり PC を再起動したりせずに更新できます。設定・辞書・学習は引き継がれます。
- **削除**: Windows の「設定」→「アプリ」→「インストールされているアプリ」から **Asteria 日本語入力**（および CUDA アドオンがある場合は両方）をアンインストールします。個人データまで完全に消す場合は `%USERPROFILE%\AppData\LocalLow\Asteria` フォルダを削除してください。

## データとプライバシー

Asteria は **100% オフライン** で変換・推論を行います。利用統計（テレメトリ）や入力テキストの外部送信は一切ありません。

`%USERPROFILE%\AppData\LocalLow\Asteria\` に保存される主なファイル：

| ファイル | 用途 |
| :--- | :--- |
| `asteria_settings.json` | 品質設定・ライブ変換などのユーザー設定 |
| `asteria_context.tsv` | 文脈つき学習・文単位再発防止学習（最大 2,000 件。パスワード欄・シークレットでは非保存） |
| `user_dictionary.tsv` | ユーザー辞書 |
| `asteria_recent_conversions.txt` | 直近の変換記録（**既定オフ**、誤変換確認用にオンにした場合のみローカル保存） |
| `asteria_ai_status.txt` | 使用中の GPU / AI ステータス表示用 |
| `crash\crash-*.txt` | 障害時のスタック記録（最新 5 件。入力文字は記録しません） |

## 困ったとき・報告

- SmartScreen が出た場合は「詳細情報」→「実行」で続行できます。
- 候補切り替えが重い場合は品質設定を Eco にしてお試しください。
- 不具合や誤変換の報告は [GitHub Issues](https://github.com/aruiki/Asteria-Japanese-IME/issues/new/choose) へお寄せください（設定画面の診断エクスポートには入力文字は含まれません）。脆弱性報告は [SECURITY.md](../SECURITY.md) をご覧ください。
