<h1 align="center">打ちたい言葉が、Space 1回で。</h1>

<p align="center">
<strong>Asteria（アステリア）は、変換精度の高い Windows の日本語入力です。</strong><br>
長い文も、前の文の流れも読んで、最初の候補で正しく変換します。<br>
無料・オープンソース。入力した文章は外へ送りません。
</p>
